# SCQA scenario playbook / 场景化表达库

Use the actual state of evidence and relationship. Templates are adaptable narratives, not facts to insert verbatim.

## Four complication patterns / 四类冲突

1. **Task blocked / 任务受阻:** S agreed task; C obstacle; Q how to deliver within constraints; A recommended response.
2. **Known solution, execution risk / 已有方案待实施:** S known problem; C selected solution faces implementation difficulty; Q how to implement reliably; A execution design. Do not call the solution selected unless it is.
3. **Candidate needs evaluation / 备选方案待评估:** S problem; C candidate option with unresolved trade-offs; Q whether it is preferable; A comparison and recommendation.
4. **Intervention effect uncertain / 新措施效果未知:** S action taken; C uncertain outcomes or side effects; Q whether it works; A evidence-based assessment and next test. Distinguish outcomes from attribution.

## Project proposal / 项目建议书

S: client's verified challenge. C: capability, time or execution gap; mention a decision to hire advisers only if confirmed. Q: what approach and team can close the gap? A: proposed approach and fit.

Support with understanding of the problem, feasible method, relevant verified experience and credible workplan. Where experience is missing, disclose the gap and propose a pilot or partner; never invent credentials. Include scope/exclusions, deliverables, client inputs, milestones, dependencies and acceptance criteria proportional to the assignment.

**English key-line pattern:** We recommend [approach] to close [gap] within [constraint], because [decisive reasons]. The immediate decision is [ask], subject to [material uncertainty].

**中文关键句模板：** 建议以[方案]在[约束]内缩小[现状与目标差距]，主要依据是[核心理由]；本次需决定[事项]，其中[关键不确定性]须先验证。

## Progress summary / 进度小结

First report: S agreed problem; C agreed first investigation completed or partly completed; Q what has been learned; A findings and implications.

Later report: S previous conclusion; C new evidence or agreed investigation; Q what changed; A improved / unchanged / worsened / inconclusive status, with evidence. Never prescribe worsening as the expected answer.

Distinguish work performed, findings, outcome achieved and impact. If incomplete, state remaining coverage and what the evidence can support. Add blockers, recovery actions and decisions needed only when material.

**English:** The latest evidence [supports/changes/does not yet resolve] our previous view that [claim]. We recommend [next step] because [finding]; [remaining uncertainty] limits the conclusion.

**中文：** 最新证据[支持／修正／尚不能判定]此前关于[判断]的结论；基于[发现]，建议下一步[动作]，但[证据缺口]仍限制当前判断。

## Funding or resource request / 经费与资源申请

Organise three questions, not three mandatory positive claims:

1. **Why act now? / 为何现在做？** Quantify the gap and cost of delay when supported. Separate necessity from urgency; no invented crisis or deadline.
2. **Why this option? / 为何选此方案？** Compare realistic alternatives including a baseline. State the selection criteria and downside. Prefer “best among evaluated feasible options under these assumptions” to “only solution” or “completely solves the problem.”
3. **Is the value justified? / 投入是否合理？** Show total lifecycle cost, benefits, timing, uncertainty and affordability. Compliance, resilience and public-service investments may be justified without positive financial ROI; state the rationale and cost-effectiveness instead.

For numeric ROI, define ROI = (attributable benefit − total cost) / total cost over a specified period with consistent units. Avoid double counting savings, revenues, output and wider economic spillovers. Use cash-flow timing and appropriate discounting when relevant, distinguish financial from economic analysis, and verify applicable financial assumptions. Include downside/base/upside scenarios and the assumptions that could reverse the decision. Unknown inputs stay unknown; break-even analysis may be more defensible than a point forecast.

Ask for a specific amount or resource, intended use, proposed accountable owner, stage gates and reporting cadence. A request is not approval. If the full commitment cannot yet be justified, recommend a bounded evidence-gathering phase with scale/stop criteria.

**English:** Approve [amount/resource] for [bounded phase] to test [critical hypothesis]. Release further funding only if [success criteria] are met; current estimates depend on [assumptions].

**中文：** 建议批准[金额／资源]用于[限定阶段]，验证[关键假设]；达到[成功标准]后再决定后续投入，现有测算仍取决于[主要假设]。

## Illustrative constrained-innovation case / 约束创新示例

Use a generic coastal innovation district, not a claimed live project. A lightweight cross-border partnership pilot can be one option beside an existing-park upgrade and a new-build programme. Test demand, partner commitment, legal feasibility, operating capacity and cost before ranking.

**Illustrative recommendation:** Test a limited partnership pilot before committing to major construction, provided demand and partner participation can be verified. Its value is reduced upfront exposure and faster learning; it may underperform if operating coordination costs or demand weakness dominate.

**示例建议：** 若需求与合作方参与意愿可被验证，可先开展范围明确的合作试点，再决定重资产建设；优势是降低前期投入并加快验证，主要风险是协同成本与需求不足。

Illustrative targets, urgency windows, exclusive superiority claims, financial returns and authority for cross-border data/finance pilots are not established facts. Include them only as explicitly labelled targets/hypotheses or with adequate current evidence and appropriate professional review.
