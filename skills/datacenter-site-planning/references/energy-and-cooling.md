# 电力、冷却与低碳策略

## 电力：先任务边界，再选来源
业主定义IT负荷、爬坡、容许中断、维护要求与目标认证；电气专业定义正常、热天、检修、故障的全站MW/MVA、拓扑及降额。N+1/2N不直接等于Tier；Tier III关注可同时维护性，包括容量组件与分配路径。不得从电力船数量判断Tier，也不默认每个项目必须Tier III。

| 路线 | 适用性需要核实 | 主要依赖 |
|---|---|---|
| 电网 | firm容量、接入日期、运行限制、系统升级、费用与碳强度 | 公用事业书面条件、接入研究、走廊与分期 |
| 自建燃气机组／CCGT | 规模与负荷率、气源、启动与检修、排放、用地、经济性 | 燃气合同、许可、设备交期、燃料及备用体系 |
| 电力船 | 水域与靠泊、安全、燃气或液体燃料、海事、并网、实际机组拓扑 | 港口和环境批准、供应商性能、风暴与补给条件 |
| 邻近园区直供 | 合法售电和接线模式、真实可转供容量、共因失效 | 监管许可、商业合同、路权、保护与计量 |
| 可再生能源＋储能 | 时序供需匹配、充电来源、持续时间、占地与调度 | 逐时模型、气象与衰减、并网及备用保障 |

不预设电网不可行、CCGT最便宜或燃气管道必需30–40个月。所有周期取供应商、公用事业和审批计划；未知给范围及依据。FSRU需要自身泊位、管道、许可、供应和商业可行性，不是自动可用的备选。

每一期明确供电来源、可用日期、可交付IT负荷、临时与永久系统切换、远期施工隔离、谁建设／付费／运维。容量冗余与能耗分开；正常容量不能把备用设备重复计入。

## 冷却：取热、输热、排热三个层次
逐一写明服务器取热（风冷／冷板／浸没）、建筑输热（CDU、循环温度与水质）、环境排热（干冷、冷却塔、冷机、海水等）。液冷或闭式循环本身不等于零耗水。

对比集中／分布式系统时检查负荷爬坡、热天性能、模块隔离、泵能耗、管路、占地、运维和扩建，不能用100 MW作通用分界。海水方案另查生态、取排水、腐蚀、生物附着、温升、许可与泵能耗；说明WUE边界，不能直接称WUE-neutral。

概念算例（所有系数均为假设，不是设计标准）：
```
Q_MWc = IT_MW × thermal_factor
TR = Q_MWc × 1000 / 3.51685284
chiller_MWe = TR × kW_per_TR / 1000
cooling_MWe = chiller_MWe × auxiliary_factor
```
100 MW IT，thermal_factor=1.15、0.55 kW/TR、auxiliary_factor=1.15，约32,700 TR、17.98 MW冷机电力、20.68 MW含假设辅助用电。thermal_factor说明包含哪些热源，auxiliary_factor说明包含哪些泵／风机，避免重复。0.55 kW/TR相当于冷机COP约6.39，不是6.6。最终需按实际边界、气象、设备曲线和分项热量／电量校核。

吸收式冷机：热COP=冷量/输入热量，电力辅助指标另列。不能将“电等效COP 18”当热COP；按热源温度、可用热量、同时率、冷却水和备用热源核算。热源可以是合适的余热、蒸汽等，不限定必须现场发电；没有热源协议不计节能收益。

## 低碳路径
将物理供电、市场采购凭证、年度可再生比例、逐时匹配、现场燃烧与全生命周期排放分开。绿能比例的分母、周期、认可技术、证书和辖区必须定义；没有通用50%底线。

生物甲烷查可持续供应、认证与泄漏；氢混烧查体积／能量比例、机组许可、NOx和供应；氨查毒性与技术成熟度；SOFC查燃料来源及效率；CCS查捕集率、残余排放、运输封存、许可和合同。均为条件选项，不保证成熟、零碳或可采购。

经济比较使用相同IT负荷、可靠性、气象、投运日期、寿命、币种与价格基准：土地、场外升级、设备、燃料、电价结构、运维、更换、碳成本、融资与退役。分别报告CAPEX、OPEX、生命周期成本及关键敏感性。未知单价不冒充地区QS报价。税收／就业／GVA按当地证据核净值，不预设数据中心优于其他产业。
