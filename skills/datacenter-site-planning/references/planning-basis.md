# 规划设计依据与参数

参数必须带：定义、单位、首期／终期、平均／峰值、正常／高温／检修／故障工况、来源日期、责任专业、置信状态。法定限值只从已核实的辖区官方资料或项目文件录入。

## 概念阶段计算纪律（工程补充，不是详细设计）
- PUE（电能使用效率）=同一周期／边界全站电量÷IT电量。年电量估算可用 `IT_MW × 利用率 × 8760 × 年PUE`，结果MWh/年；IT_MW为装机能力时才另乘利用率。已给平均IT负荷不得重复折减；闰年调整小时数。年PUE不能直接用于峰值接入容量。
- 若仅做瞬时功率情景，用同工况全站／IT功率比，清楚标为概念假设；最终接入峰值由分项负荷、同时系数、温度及冗余运行方式校核，防止重复加冷却负荷。
- 电网 `MVA = MW / 功率因数` 仅用于对应运行点的视在功率估算，不替代短路、谐波、保护与接入研究。
- WUE（水使用效率）须明确分子是耗水还是取水、现场还是含电力上游，分母一般为IT电量；只有同边界同周期才可相乘。`L/kWh × IT_MWh × 1000 / 1000 = m³`。全年指标不能代替峰时水力计算。
- 水量平衡：按系统分别列取水、回流／回用、蒸发、漂水、排污和储量变化；内部循环量不能算成外部取水，废液不能混作清洁雨水。消防与生活水独立核对适用条件。
- 储水概念值 `净补水流量(m³/h) × 需保障小时(h)`；另由专业核有效容积、不可用水量、消防预留、补水中断、质量和共因故障。
- 单元计数：所需运行单元 `ceil(需求/该设计工况可用单元能力)`，再按明确拓扑增加备用；环境降额、维修隔离、共享接口需另查。不能从总装机量推断Tier。
- 用地账本：不重叠区域分别计建筑基底、机电场地、道路／装卸、储水与处理、排洪／绿地／缓冲、分期预留；明确屋顶或重叠区避免重复计面积。每项设备用供应商包络加专业检修／安全条件，不采用固定MW/ha系数。

## 从参数到总图的强制闭环
每个接入点 → 走廊／路权 → 场内接口 → 设施包络 → 最终用户 → 废物流／排热出口，均须在图上找到。场外工程记录谁建设、谁付费、谁运维、何时可用；既有公共容量扣除已承诺需求，再由公用事业确认，不自行宣布剩余容量可用。
