# 设施检查、原则平衡与阶段闸口

## 设施／接口核对
每一项填“需要／条件适用／不适用”，不适用给出依据；需要的设施必须有容量来源、包络、图号、场外接口、运维责任与检查证据。不是所有项目都需独立变电站、水塔或自建污水厂。

| 设施组 | 检查对象 | 通过证据与常见问题 |
|---|---|---|
| IT与运营 | 大厅、网络／进线间、控制室、支持办公与卫生、备品 | 业务任务书与布置图一致，设备替换不封堵安全路径 |
| 主供电 | 进线廊道、变电／配电、线路与保护接口 | 公用事业容量及日期函、单线图、场内外用地；近站不等于能接 |
| 备用电 | UPS／电池、备用电源、燃料储运；按方案选配 | 可靠性说明、通风／消防／泄漏与排放审查；两路同沟或共用控制点须揭示 |
| 冷却与排热 | 取热端、循环系统、冷机／冷却塔／干冷器、泵、CDU等按技术配置 | 完整系统图及热天性能、噪声／热回流，不能只写“液冷” |
| 水 | 分质水源、计量、防回流、处理、泵、储水和备用模式 | 峰时量质压确认、水量平衡；工艺／生活／消防的接口符合本地要求 |
| 排水与废物 | 雨水、污水、工艺排污、废液和危废／电子废物暂存 | 接纳／排放条件、预处理、取样、泄漏收集与合法收运路径 |
| 通信 | 按业务需要的多路接入与进线间 | 运营商物理路由证据与共因故障审查；两个合同不代表两条独立路 |
| 交通后勤 | 门岗、停车、装卸、燃料车等候、消防道路、吊装及替换通道 | 车辆轨迹、荷载／净空和应急交通方案；不得靠占用公共街道解决排队 |
| 安全与社区 | 安防边界、消防救援、缓冲、声学措施、照明、排气与监测 | 专业审查和受体预测；绿化不能替代隔声／排放性能证据 |
| 场外与分期 | 电网升级、水务扩容、光纤与道路ROW、施工临设、远期用地 | 权利、资金、交付节点、运维和退出责任；远期施工不破坏已投运路径 |
| 可选协同 | 余热外供、回用水、储能、现场可再生能源 | 各自可行性、热用户／水源协议、备用与商业边界；无受益方不计收益 |

## 检查哪些工况
至少按项目相关性检查：正常运行；热天峰值与干旱同时发生；一条关键供给中断；计划维护；停电期间燃料补给及消防可达；建设与运行重叠；全园区最终负荷与其他已承诺项目叠加；负荷低于预测／退出。每项写受影响设施、服务降级、恢复路径及谁验证，不凭一张总图宣称韧性。

## 怎样平衡原则
先把合法性、生命安全、可靠容量和不可接受环境风险作为门槛；未证实标“待证”，不能靠高经济分补偿。可行方案再比较：

| 常见冲突 | 需要比较的证据 | 选择条件 |
|---|---|---|
| 节水 vs 电耗／设备占地 | 相同IT负荷、当地气象和热天性能；水源压力、用电与设备包络 | 水资源约束优先满足；剩余方案比较生命周期成本，不能单看PUE |
| 冗余 vs 土地／噪声／空气 | 业务中断成本、拓扑、设备数量及同时测试／应急排放 | 业主确认可靠性目标；专业确认路径和影响可接受后取舍 |
| 低地价 vs 场外工程／交付 | 全部电水路光纤升级、权利、交期及成本承担 | 用总交付成本和可用时间比较，不能只比土地单价 |
| 紧凑布置 vs 维护／扩建／邻地 | 运维与替换轨迹、热回流、声学与分期界面 | 不挤掉必要维护、安全和通道空间后再压缩 |
| 清洁能源承诺 vs 实际供能／排放 | 电网与备用电排放、采购匹配时段、许可、储能持续时间 | 分别报告市场凭证与物理供电；不自动称24/7零碳 |
| 余热利用 vs 复杂度／承诺 | 热量温度、用户距离、逐时／季节需求、管线、投资与合同 | 有可验证需求与交付责任才计入收益；保留无用户时排热路径 |
| 经济收益 vs 公共资源机会成本 | 净税收、就业口径、公共扩容及运维、挤占住房／产业容量 | 单列谁受益谁承担，业主与地方权责主体决定分摊 |

如需加权评分：权重由项目决策者确认并总和100%；未确认只呈现无权重比较。每项给证据及不确定范围，分数方向一致。做一个权重／关键参数敏感性场景；排名翻转就报告选择不稳健。提供推荐方案及适用条件，不替人决定专业风险偏好。

## 阶段冻结条件
- G0 选址短名单：用地、容量时序、通道、灾害和敏感点具备可验证路径；否则只能作候选。
- G1 规划依据：负荷／冷却／可用性与电水排条件、气象及分期已对齐；缺证据明确冻结禁区。
- G2 概念总图：设施能装下，场外接得上，维护换得出，污染与交通有可行缓解；残余风险有责任人。
- G3 规划提交前：适用规定核实、专业审查、许可路径和条件关闭；由项目专业负责人确认提交成熟度。本skill不作竣工验收或Tier认证。
- 运行承诺交接：计量与监测边界、频率／阈值、数据责任、投诉／纠偏及技术变更复核触发条件写入运营交接；实际数值由许可和设计确定。
