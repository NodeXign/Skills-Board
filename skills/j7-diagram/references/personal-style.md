# Personal Notion / Hairline preset

默认浅色：paper #FFFFFF，paper-2 #FAFAFA，ink / ink-strong / accent / link #231F20，muted #616161，soft #6B6B6B，rule rgba(35,31,32,0.16)，rule-solid #8A8A8A，accent-tint rgba(35,31,32,0.04)。颜色、暗色与项目品牌以当次要求为准。

逻辑图：1 CSS px 细线边框；承载含义的箭头和连接线须保持足够对比度。大量留白，无阴影、渐变或默认彩色卡片。默认系统无衬线字体，中文使用系统中文字体回退。强调依靠字重、少量深色实心块与布局。多组数据优先用标签、虚实线、形状区分，必要时再按需求用颜色。

插画：遵循 Notionaly 的暖黑单墨、白底、收放变化的笔触与少量实心块。人物线条不要机械地统一为 1px；hairline 用于页面结构和逻辑图。动作清楚，场景简洁。用户提供的参考图可指导风格，不自动复制其文字、构图或姿势。

信息图：采用真实 HTML 文字与准确 SVG 数据图形，搭配独立插画资产，保留可编辑源文件。

## Hairline 与 Diagram Design

Diagram Design 管信息结构与编辑排版。使用 4px 网格、1px 结构线和 1–2 个视觉焦点。统一间距、节点边缘与标签基线，删除重复连线与装饰。默认用暖黑字重或高对比边缘强调，品牌色按当次需求使用。

Hairline 管等轴测与物件线稿。统一投影方向与线宽，轮廓清楚，内部分缝降低对比。遮挡按从远到近处理，用与底色一致的不透明面盖住背后的线，虚线定位导引放在物件后。分层与爆炸间距要能看懂组装关系。静止画面应独立成立，可读性优先于立体效果。

流程、时序、指标默认保持平面。空间结构或部件拆解确实受益时才用等轴测。可交互图用 Hairline 官方组件工作流，检查静止状态、交互极限和减少动态效果模式。静态图直接交付可编辑 SVG 或 HTML。混合信息图用 Notionaly 处理人物线稿，线宽随笔势变化。
